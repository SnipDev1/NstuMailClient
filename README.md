# Почта НГТУ (NstuMailClient)

Нативный клиент для корпоративной почты НГТУ (`https://mail2.nstu.ru`, Microsoft Exchange 2016) на базе Kotlin + Jetpack Compose / Compose Multiplatform:
- **Android** (`:app`) — телефон и планшет (Kotlin + Jetpack Compose + Material 3)
- **Desktop** (`:desktop`) — Linux (`AppImage`) и Windows x64 (`zip` с JRE 17)
- **Общее ядро** (`:core`) — нативный EWS-клиент (`/EWS/Exchange.asmx` поверх HTTPS + HTTP/1.1 + NTLMv2)

## Возможности
- **Нативный EWS-клиент** (`/EWS/Exchange.asmx` поверх HTTPS + HTTP/1.1 + NTLMv2):
  - Полное дерево системных и пользовательских папок (включая вложенные подпапки): создание, переименование, удаление, очистка, «Отметить все прочитанными» и дедуплицированные счётчики по поддереву.
  - Фильтры (Все, Непрочитанные, С флажком, С вложениями), поиск по папке или по всем папкам, pull-to-refresh и постраничная подгрузка.
  - Настраиваемые жесты (свайп влево/вправо во всех папках), массовое выделение писем (прочитано, перенос, удаление), флажки и важность.
  - Система иерархических тегов (`["1", "2"]`), перенос структуры тегов в папки и автосортировка входящих с маршрутизацией в «Несортированные».
  - Чтение HTML/текстовых писем (в изолированном `WebView` без JS на Android и в нативном Compose-рендерере на Desktop с поддержкой inline-картинок `cid:` и адаптацией тёмной темы), скачивание и открытие вложений.
  - Написание писем: кому/копия/СК, важность, прикрепление файлов, автодополнение по каталогу НГТУ (GAL), сохранение и редактирование черновиков, ответ/ответ всем/пересылка, пометка спама.
  - Мгновенные Push-уведомления (EWS Streaming Subscription + фоновый сервис/WorkManager на Android, системные уведомления на Desktop) и правила отключения по папкам/отправителям.
  - Разделы **Контакты и адресная книга НГТУ** и **Календарь** (просмотр, создание и удаление событий).
- **Безопасность**:
  - Учётные данные не зашиты в код; на Android шифруются через `AndroidKeyStore` (`AES-256-GCM`), на Desktop — через локальный AES-GCM ключ с правами `0600`.
  - Разрешён только HTTPS (`cleartextTrafficPermitted="false"`).
- **Автообновления из GitHub Releases**:
  - При запуске и вручную в Настройках клиент проверяет последний релиз репозитория `SnipDev1/NstuMailClient` (поддерживаются каналы `Актуальная` и `Тестовая`).
  - Для выпуска новой версии используйте `./scripts/release.sh`:
    ```bash
    # Один раз положите GitHub PAT (Contents: Read & Write) в .release.env:
    # GITHUB_TOKEN=ghp_...
    ./scripts/release.sh 1.0.12 "Описание изменений" --stable
    ```
    Скрипт создаст/использует keystore (`~/.android/nstumail-release.jks`), обновит `versionCode`/`versionName`, прогонит тесты, соберёт подписанный release APK, Linux AppImage и Windows x64 ZIP, создаст тег и опубликует GitHub Release.
    Для тестовой локальной сборки без публикации: `./scripts/release.sh 1.0.12 --dry-run`.
